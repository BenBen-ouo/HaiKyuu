# AI 進攻與防守能力

本文件記錄目前能力拉條的遊戲行為，修改難度時一併更新。數值的實際來源為 `model/ai/AiTuning.java`，反應曲線為 `AiDifficulty.java`；本文件不取代程式設定。

兩條拉條各為 1～100，進場後固定；整場重開保留難度並清空習慣統計。入門為 1～20、簡單 21～40、普通 41～60、困難 61～80、專家 81～100。門檻以外的機率及誤差逐點變化，不是只有五組固定行為。

## 進攻拉條

| 項目 | 從哪裡開始有差異 | 各區段實際變化 |
| --- | --- | --- |
| 發球種類 | 1 即有普通／低網，2 起可能短發／天花板球 | 後兩種的條件抽樣機率隨進攻提高；選跳發時不走此分支，不代表所有球種一起等比例增加 |
| 跳發 | 普通，41 起 | 入門、簡單不使用；解鎖後機率逐點提高。依接觸位置選擇可用的現有跳發變化 |
| 快攻配球 | 簡單，21 起 | 入門不使用；簡單起隨能力增加使用率。MB 只在實際快攻球路可達時安排起跳 |
| Setter 跳舉 | 普通，41 起 | 簡單以下不使用；解鎖後逐點提高嘗試機率，還須實際可接觸到球 |
| 負節奏 | 簡單，21 起 | 入門不使用；解鎖後逐點提高。站舉時以 Setter 接觸前約 42～48 幀開始 WS 助跑／後排起跳，球路不允許則改其他節奏 |
| 第一／第二節奏 | 基本能力 | MB 第一節奏須已解鎖快攻配球；WS／後排第二節奏在出球頂點附近開始動作。時機擾動限於目前演算法設定，不改角色速度 |
| 進攻人數 | 41 起雙人，61 起三人 | 入門、簡單單人；普通可能雙人；困難以上可能三人。人數是規劃上限，角色必須有可達窗口，已起跳者持續占用名額 |
| 假扣真舉 | 困難，61 起 | 60 以下禁止，包含備援。現行規劃器在 Setter 接第一球後可安排 WS／後排空中舉第二球；可直接攻擊時也會評估直接攻擊，沒有新增 Setter 主動二次扣球 |
| 空檔判斷 | 普通，41 起 | 40 以下只排除已知無法過網／出界的選項，再隨機選可行球路；41 起才比較對手防守空隙與攔網 |
| 球路選擇 | 基本扣球從 1，吊球從 21 | 入門不吊球；簡單以上可能短吊、長吊。MB 正常扣球可用時，吊球候選機率額外降低；只有吊球可用時仍可選吊球 |
| 組織反應 | 1～100 連續改善 | 進攻開始的等待、發球決策使用進攻反應曲線，與防守拉條分開 |

進攻評估遵守現有角色、球速與碰撞規則，不因高難度放大框或增加跳躍力；規劃窗口有時無法實際完成，仍可失誤。

## 防守拉條

| 項目 | 從哪裡開始有差異 | 各區段實際變化 |
| --- | --- | --- |
| 反應速度 | 1～100 連續改善 | 對公開球路變化的反應逐點加快；等待不停止物理、動畫或其他角色更新 |
| 接球位置誤差 | 1～100 連續改善 | 入門較大，專家較小；誤差套在公開位置／速度的自由飛行估計，不讀未來觸球結果 |
| 跑步／撲救 | 所有難度都有 | 共用可達窗口判斷，考慮跑步加速及撲球減速；能力透過反應與估計誤差影響結果，沒有另一套專家物理 |
| WS／後排分工 | 所有難度都有 | WS 短球、後排長球；WS 撲早或失去接球窗口後，後排可補接。原則相同，不分階段新增角色能力 |
| 後排退防 | 所有難度都有 | 本隊扣球已向對場飛行時就開始回防，不等對手接起第一球；對手組織時維持三米至九米預備區。習慣資料依能力影響深淺站位，實際追球不受預備區限制 |
| 本隊進攻時提前補位 | 普通，41 起 | 入門、簡單不做；後排沒有攻擊／假跑／第三球支援任務時，才可能從底線附近提前前進至後場中央。每次本隊第一球後抽樣一次，之後不每幀重抽 |
| 攻擊者預判 | 1～100 連續改善 | 低能力較偏隨機，高能力更重視可見助跑／起跳及習慣；不讀對手未公開輸入 |
| 節奏預判 | 簡單，21 起 | 入門固定預判第二節奏，快球與近網估計不能把它提前改成快攻時機；簡單起結合猜測、公開動作及習慣預判 |
| 攔網時機 | 1～100 連續改善 | 時機誤差逐點縮小；入門另保留第二節奏等待，因此對快攻較晚起跳 |
| 補攔 | 普通，41 起 | 簡單以下同一對手組織只允許首次攔網起跳；普通起可落地後再判斷。次數取自 MB 實際狀態，不因重新預測重置；若已使用攔網接觸，仍遵守原本接觸限制 |
| 對手習慣 | 所有難度都記錄 | 攻擊落點按攻擊者及節奏分開記錄；高能力更重視習慣。反覆快速深球還會影響後排進攻／假跑安排，避免落地後來不及回防。樣本先驗避免單次觀察支配決策，整場重開清空 |

發球與攻擊的落地位置分開累計；攻擊再依後排／MB／WS、負一／第一／第二節奏分類。只記已觀察到出手、未被本隊接觸或撞網中斷的首次實際落地，得分後反彈不重複記錄；被成功接起的球不產生落地樣本。無法確認舉球與起跳先後時，不視為快速節奏。

反覆的負一／第一節奏深球會累積回防風險。樣本足夠且依防守能力加權後達門檻時，安排後排攻擊或假跑前，會估計其起跳、落地及跑回習慣落點的時間。有其他可行攻擊者時優先保留來不及回防的後排；後排是唯一可用攻擊點或負責空中舉球救援時仍保留機會。這是保守的戰術估計，不讀取對手下一球決策，也不保證接起。既有多人進攻與戰術解鎖門檻維持不變。

## 連續變化的數值範圍

以下為各區段的約略範圍，不是成功率。反應時間另有約 ±8% 隨機差異，最後換算為整個遊戲 tick。

| 設定 | 入門 1～20 | 簡單 21～40 | 普通 41～60 | 困難 61～80 | 專家 81～100 |
| --- | --- | --- | --- | --- | --- |
| 進攻／防守各自反應時間 | 0.40～0.30 秒 | 0.30～0.25 秒 | 0.25～0.20 秒 | 0.20～0.15 秒 | 0.15～0.12 秒 |
| 接球位置最大估計誤差 | 約 ±45～30 px | ±30～18 px | ±18～9 px | ±9～3.8 px | ±3.8～2 px |
| 攔網時機誤差參數 | 約 ±20～14 幀 | ±14～9 幀 | ±9～6 幀 | ±6～4 幀 | ±4～3 幀 |

入門攔網把時機誤差取為延後量，再加第二節奏等待，不套用可提前的正負誤差。進攻出手／起跑窗口目前共用 ±2 幀排程擾動，沒有額外以能力改變這個常數。

各使用率的公式、上限集中在 AiTuning：

- 快攻配球：21 起，條件機率約由 22% 提高至 50%；必須不是 Setter 自己接第一球。
- 負節奏：21 起由小機率逐點升至 55%；Setter 跳舉：41 起升至 95%。上述是嘗試方案的抽樣，不代表實際完成率。
- 跳發：41 起逐點增加，最高選用機率約 48.75%；正常／低網／短發／天花板分支另計。
- 雙人：41 起，選擇至少兩人的機率為 `(進攻 - 40) / 60`。三人：61 起，在已選多人時再乘 `(進攻 - 60) / 40`。仍須角色可配合。
- 主動假扣真舉偏好：61 起升至 28%；找不到直接攻擊窗口時，已解鎖的空中舉球備援另行評估，因此不是總使用率上限。
- 一般吊球候選：21 起，最高約 28%；MB 正常扣球可用時再乘 0.15，最高約 4.2%。候選不保證最後被選中；只有吊球可過網時不套用此機率限制。
- 後排提前補位：41 起，抽樣機率為 `0.9 × (防守 - 40) / 60`，最高 90%；後排已被進攻規劃保留時不執行。
- 快速深球回防：至少 3 個攻擊落地樣本；快速深球比例以 8 個先驗樣本平滑，再乘防守能力的正規化值，達 0.20 才影響後排參戰安排。深球指本方底線至向網前三米，含球半徑的底線邊緣；回防比較使用保守的起步跑速及對方最早 30 幀回擊預算。參數集中在 `AiTuning`，不是新增的階段解鎖或成功率。
- 普通以上的球路選擇會評估空檔；改選隨機可行方案的機率隨進攻提高而下降，最高能力仍保留約 2%。這不是出界／掛網機率。40 以下直接從可行選項抽樣，不套用普通以上的評分選擇。

## 調整與驗證入口

- 參數與解鎖值：`model/ai/AiTuning.java`；標籤與反應曲線：`AiDifficulty.java`。
- 進攻／發球：`OffensePlanner`、`AttackOptions`、`ServePlanner`；防守／補位：`DefensePlanner`。
- `AiPolicyTest`：門檻、空檔選擇、負節奏及補攔；`AiTacticsTest`：實際接球、進攻轉換與提前補位；`AiMatchTest`：完整對局、能力分離與重開。
- `model.ai.AiLearningTest`：情境落點、樣本信心、落地去重與重開、左右對稱的實際進攻安排及接球後遭遇 MB 快攻的連續攻防。
- 日常及打包測試入口見 [AGENTS.md](../AGENTS.md)。自動案例結果不能當成真人得分率或勝率。
